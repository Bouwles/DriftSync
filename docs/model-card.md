# DriftSync Model Card

## Intended Use

DriftSync predicts short-horizon error risk during a synthetic sustained-attention task. It is intended for research demos, portfolio review, and experimentation with behavioral sequence modeling.

## Not Intended For

- Medical diagnosis or clinical fatigue detection.
- Workplace monitoring or automated employment decisions.
- Safety-critical deployment without real human validation and ethics review.

## Inputs

The model consumes a rolling window of 15 normalized behavioral features, including reaction time, correctness, rolling error rates, streaks, response timing variance, and fatigue proxy features.

## Outputs

- Probability of an error in the next configured horizon.
- Uncertainty estimate when using Monte Carlo Dropout.
- Warning flag when probability or uncertainty exceeds thresholds.

## Training Data

The default pipeline uses synthetic sessions generated by DriftSync's headless simulator. Synthetic data is useful for engineering verification, but it is not a substitute for real user data.

## Evaluation

The checked-in summary reports synthetic test-set metrics for LSTM and Transformer models. These metrics demonstrate the pipeline, not field performance.

## Ethical Notes

Any real deployment would need consent, clear user control, data minimization, careful threshold tuning, and validation across users and tasks.
